# sistema-restaurante

## Descrição
Sistema desenvolvido em Java para gerenciamento
de pedidos de um restaurante.

- Nome do integrante 2 - Vitor

## Tecnologias
- Java
- Apache NetBeans
- Git
- GitHub

## Funcionalidades
- Cadastro de pedidos
- Cadastro de itens do cardápio
- Cálculo dos valores
- Aplicação de descontos

## Como executar
1. Abra o Apache NetBeans.
2. Clique em File > Open Project.
3. Selecione a pasta do projeto.
4. Execute o programa.
